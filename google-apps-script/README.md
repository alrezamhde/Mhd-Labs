# وصل کردن رزرو سایت به Google Calendar (یک بار، حدود ۱۰ دقیقه)

فرم رزرو داخل سایت از طریق این اسکریپت به تقویم گوگل خودت وصل می‌شود. اسکریپت روی حساب گوگل خودت اجرا می‌شود؛ هیچ سرور یا هزینه‌ای لازم نیست.

## ۱. ساختن اسکریپت
۱. با همان حساب گوگلی که تقویمت روی آن است برو به script.google.com و New project را بزن.
۲. اسم پروژه را بگذار MHD Booking.
۳. همهٔ متن داخل Code.gs را پاک کن و محتوای فایل Code.gs همین پوشه را جایش بچسبان. ذخیره کن (Ctrl+S).

## ۲. روشن کردن لینک Google Meet
۱. در منوی سمت چپ، کنار Services روی + بزن.
۲. Google Calendar API را انتخاب کن و Add را بزن.
(اگر این کار را نکنی رزرو باز هم کار می‌کند، فقط لینک Meet ساخته نمی‌شود.)

## ۳. تست و دادن دسترسی
۱. از لیست بالای ویرایشگر تابع testSetup را انتخاب کن و Run را بزن.
۲. گوگل اجازه می‌خواهد. حساب خودت را انتخاب کن. اگر پیام «Google hasn’t verified this app» آمد، Advanced و بعد Go to MHD Booking را بزن و Allow کن (اسکریپت مال خودت است).
۳. در Execution log باید تعداد زمان‌های آزاد و چند نمونه را ببینی.

## ۴. انتشار
۱. بالا سمت راست Deploy → New deployment.
۲. روی چرخ‌دنده کنار Select type بزن و Web app را انتخاب کن.
۳. Execute as: **Me** — Who has access: **Anyone**.
۴. Deploy را بزن و Web app URL را کپی کن (آخرش ‎/exec است).

## ۵. گذاشتن آدرس در سایت
فایل booking.js را باز کن و آدرس را بین دو گیومه بگذار:
```
export const BOOKING_API = "https://script.google.com/macros/s/....../exec";
```
فایل را دوباره در گیت‌هاب آپلود کن. برچسب «Preview mode» خودش حذف می‌شود و رزروها واقعی می‌شوند.

## تنظیمات (بالای Code.gs، داخل CONFIG)
- ساعت‌های کاری هر روز: `hours` (پیش‌فرض دوشنبه تا پنج‌شنبه ۱۰ تا ۱۸، جمعه ۱۰ تا ۱۶، به وقت تورنتو)
- طول جلسه: `durationMin` (۳۰ دقیقه)
- فاصلهٔ خالی قبل و بعد از جلسه‌های دیگر: `bufferMin` (۱۵ دقیقه)
- حداقل فاصله تا رزرو: `minNoticeHours` (۱۲ ساعت)
- تا چند روز جلوتر: `daysAhead` (۳۰ روز)
- حداکثر جلسه در روز: `maxPerDay` (۴)
- ایمیل خبر برای خودت: `notifyMe`

هر وقت Code.gs را تغییر دادی: Deploy → Manage deployments → مداد (Edit) → Version: New version → Deploy. آدرس عوض نمی‌شود.

نکته: اسکریپت هر رویدادی که در تقویمت هست (به جز رویدادهای تمام‌روز) را «مشغول» حساب می‌کند، پس زمان‌هایی که جلسه داری خودکار از لیست حذف می‌شوند.
