# MHD — Scroll Portfolio (نسخهٔ سه‌بعدی)

## نصب روی گیت‌هاب
۱. فایل ZIP را از حالت فشرده خارج کنید.
۲. در مخزن Mhd-Labs از Add file → Upload files استفاده کنید.
۳. همهٔ محتویات این پوشه (index.html، style.css، app.js، booking.js و پوشه‌های media، vendor و about) را در ریشهٔ مخزن قرار دهید و فایل‌های همنام را جایگزین کنید.
۴. Commit changes را بزنید و بعد از انتشار GitHub Pages صفحه را با Ctrl+Shift+R رفرش کنید.

پوشهٔ vendor جدید است و حتماً باید آپلود شود (کتابخانه‌های GSAP، ScrollTrigger، Lenis و Three.js داخل آن است).
نیازی به build یا نصب پکیج نیست.

## ترتیب صفحه
- لودر با شمارنده ← هِروی MHD با کرهٔ ذرات سه‌بعدی (با اسکرول حروف از هم باز می‌شوند)
- متن معرفی که کلمه‌به‌کلمه روشن می‌شود
- شش پروژه: ویدیو بالا می‌آید ← کنار می‌رود و توضیحات ظاهر می‌شود ← توضیحات می‌رود و ویدیو بالا می‌رود
- پس‌زمینهٔ ذرات برای هر بخش به یک شکل جدید تبدیل می‌شود (حلقه، مارپیچ، موج، مکعب، کهکشان، گره)
- انتها: دکمهٔ «Contact me» که صفحهٔ رزرو اختصاصی خود سایت را باز می‌کند (انتخاب روز، ساعت، مشخصات و تأیید)

ویدیوها بی‌صدا، خودکار و همیشه در حال لوپ هستند و هیچ دکمه‌ای ندارند.

## وصل کردن رزرو به Google Calendar
راهنمای قدم‌به‌قدم در google-apps-script/README.md است. تا وقتی آدرس اسکریپت را در booking.js نگذاری، فرم در حالت پیش‌نمایش است و رزرو واقعی ثبت نمی‌شود.
پوشهٔ google-apps-script لازم نیست در گیت‌هاب آپلود شود.

## ویرایش متن‌ها
عنوان، دسته و توضیح هر پروژه مستقیماً داخل index.html در بخش `<section class="project" ...>` همان پروژه است.
